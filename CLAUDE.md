# easyClaude (plugin source)

Contributor rules live in CONTRIBUTING.md. Two of them apply to every commit and release:

- Start each commit message and pull request title with a tag: `[feature]`, `[bugfix]`, `[changes]`, `[docs]`, `[tests]` or `[release]`.
- Release notes are public: Added / Changed / Fixed, neutral wording, what changes for the user, each entry linked to its pull request, then the update commands.
