<context>
I run a small online plant shop, and this repository is its website. I am not a programmer, so I cannot check the code myself.
</context>

<problem>
The automated tests keep failing, and I do not understand why.
</problem>

<task>
Find out why the tests fail, and make the test suite pass.
</task>

<success_criteria>
- Every test passes.
- If the code is wrong, the code is fixed. A test changes only if the test itself is wrong, and you explain why.
- No test is deleted, skipped or loosened to make it pass.
</success_criteria>

<constraints>
- Read the failing tests and the code they test before you change anything.
- Make the smallest change that fixes the cause.
</constraints>

<report>
When you finish, explain in plain, non-technical words what was wrong, what you changed and how you checked it. If you could not check something, say so.
</report>
