# Mellu.mate hero

The README uses concept 9 (`concept-9.webp`, `concept-9-logo.webp`): twelve pastel stationery stickers in a ring around "Mellu.mate", five with small faces, on notebook grid paper.

`docs/art/draw.py` draws it as SVG, and `docs/art/render.sh` renders it into `docs/assets/`: the hero in light and dark (`hero-light.png`, `hero-dark.png`, 1640x820, shown at 820 wide), the divider (`divider-light.png`, `divider-dark.png`), and the square logo (`logo.png`, 512x512) for the GitHub avatar and social preview. Every object and letter is a drawn shape, so the objects have their real form and the name is spelled exactly.

Earlier rounds, removed on 2026-10-15 and still in the git history: four AI scenes with a round mascot (concepts 1 to 4), four AI versions with the name in balloon letters (5 to 8), and concept 9 without faces (10). The AI versions drew some objects wrong and split the name over two lines.
